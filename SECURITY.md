# Sécurité

GitHub prend au sérieux la sécurité de ses produits et services logiciels, y compris l'ensemble des dépôts de code open source gérés via ses organisations GitHub, comme [GitHub](https://github.com/GitHub).

Même si [les dépôts open source sont en dehors du périmètre de notre programme de bug bounty](https://bounty.github.com/index.html#scope) et ne sont donc pas éligibles à des récompenses, nous veillerons à ce que votre signalement soit transmis aux mainteneurs concernés pour correction.

## Signaler des problèmes de sécurité

Si vous pensez avoir découvert une vulnérabilité de sécurité dans un dépôt appartenant à GitHub, veuillez nous la signaler via une divulgation coordonnée.

**Merci de ne pas signaler de vulnérabilités de sécurité via des issues, discussions ou pull requests publiques sur GitHub.**

Envoyez plutôt un email à opensource-security[@]github.com.

Merci d'inclure autant d'informations que possible parmi celles listées ci-dessous, afin de nous aider à mieux comprendre et résoudre le problème :

  * Le type de problème (par exemple, dépassement de tampon, injection SQL, ou cross-site scripting)
  * Les chemins complets du ou des fichiers source concernés par le problème
  * L'emplacement du code source affecté (tag/branche/commit ou URL directe)
  * Toute configuration spéciale nécessaire pour reproduire le problème
  * Les étapes détaillées pour reproduire le problème
  * Une preuve de concept ou un code d'exploitation (si possible)
  * L'impact du problème, y compris la façon dont un attaquant pourrait l'exploiter

Ces informations nous aideront à traiter votre signalement plus rapidement.
