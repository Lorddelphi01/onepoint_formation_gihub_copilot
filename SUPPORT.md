# Support

## Comment signaler des problèmes et obtenir de l'aide

Ce projet utilise les issues GitHub pour suivre les bugs et les demandes de fonctionnalités. Merci de rechercher parmi les issues existantes avant d'en créer une nouvelle, afin d'éviter les doublons. Pour un nouveau problème, créez une nouvelle issue pour votre bug ou votre demande de fonctionnalité.

Pour toute aide ou question concernant l'utilisation de ce projet, merci de créer une issue.

## Politique de support GitHub

Le support de ce projet se limite aux ressources listées ci-dessus.
